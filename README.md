# AzexAI Systems

Public website for AzexAI Systems — operator of AzexAI VSM, a platform for verifiable analytical results.

Languages: Azerbaijani, Russian, English.

## Develop

```bash
npx pnpm@9.15.4 install
npx pnpm@9.15.4 dev
```

Open `http://localhost:3000`. The default locale is Azerbaijani (`/az`).

On Windows, do not run this project from a folder whose name contains `İ`. Use this ASCII path: `C:\Users\ASUS\Desktop\azexai-web`.

## Platform access

Set `NEXT_PUBLIC_VSM_URL` when the AzexAI VSM platform domain is live. Until then, Access CTAs request access through Contact.

## Notes

Content is public-safe. The site does not disclose formulas, weights, internal variables or reconstructable methodology.
